# Ballistic documentation

This folder documents **Ballistic itself**: what it can do, how to set it up and
how to develop on it. Research into the original game lives in a separate
repository.

Planned pages:

- `getting-started.md`: building the asset bundle, running the game
- `features.md`: what's implemented, and options beyond the original
- `building.md`: building from source on Windows/Linux/macOS
- `architecture.md`: crate layout and engine overview
- `bundle-format.md`: the `.bpk` bundle specification
